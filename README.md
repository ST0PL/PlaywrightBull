# PlaywrightBull
A C# .NET CLI app using Playwright to scrape the BullMC website (EasyDonate-powered), featuring a handcrafted console UI table.
## Features
- **Resources-based localization**
- **Handcrafted CLI table component**
- **Data caching**
## Localization

|Language|Status|
|:---|:---|
|English|100% ✅|
|Russian|100% ✅|
